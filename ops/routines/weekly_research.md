# Optional weekly evidence review

Disabled unless the operator deliberately creates it in Grok Bot after a successful one-time run. Suggested cadence: Monday 08:00 in the operator's chosen timezone. Do not assume a timezone or create it on install.

Saved prompt:

```text
Run the IRIN research skill against the watchlist and permitted sources I configured for this routine. Recheck the demand-to-cash-flow chain and the strongest opposing evidence. Report only meaningful changes, new blockers, failures or required input in this chat. If nothing material changed, stay quiet. Never relabel old data as current, invent a successful fetch, or force a qualifying result. Include source observation and availability dates. All results remain RESEARCH_ONLY. Do not trade, send email, message anyone else, modify remote databases, publish, or access unrelated files. If inputs are missing, report the missing prerequisite.
```

Record the owning Bot, watchlist, timezone, allowed sources, retry policy and output destination in the routine's private settings. Those values are not repository defaults.
